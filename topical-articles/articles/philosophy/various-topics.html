Thoughts on Various Topics

Time

Time is not a "thing" itself, but a function of the fact that entities in reality demonstrate the ability to change. If certain processes take place at a consistent interval, they become useful measures of "time" which can be used to compare how long other events take place. For example, one "second" is derived from the behavior of a Cesium-133 atom.

As such, it is nonsense to talk about being "outside of time", unless the system is entirely static. If there is change, there is time.

The concept of "change" becomes difficult when considering the first cause. If the first cause is one single thing, then any form of "change" is difficult to conceive of. For a change, which is basically an "event", to take place, there must be a "trigger" - a condition being present which initiates the conversion from "event not taking place" to "event taking place". But, a trigger usually operates at a level above the event itself, as part of the event's operation within a system.

For example, consider the event "an atom of gold is created in a particle accelerator". The event itself is triggered by a combination of certain atoms being in particular positions, enormous amounts of energy being present, and the properties/behaviors of atoms within our reality. Without those conditions, the event cannot take place.

But, if there is "one thing", such as is typically thought to be the case when considering the first cause, there would be no system in which it is operating which can provide conditions in order for any change to take place, unless one identifies the first cause with the "trigger" and "event" simultaneously, meaning one just is the other. And that is not to say "these 3 things are being called by one name - the first cause, a trigger, and an event, all rolled up under the term 'first cause'". It is to say that the first cause just is the trigger, and the trigger just is the event.

Therefore, it is either the case that the first cause was not "one thing" in the absolute sense, or, it is the case that the first cause can be identified with its subsequent effects.

Explanations for the First Cause

Considering how the first cause is able to exist is a profoundly difficult problem, and rejecting certain "wrong answers" helps to sharpen the discussion.

Firstly, the first cause does not exist by any type of recursion/self-causation. The first cause cannot be said to have "made itself exist". Making oneself exist is as impossible as nothing turning into something, and in fact, the two are identical, because before the first cause existed, it was not there to cause itself to exist.

Secondly, there can be no principle or rule external to the first cause which can explain its existence. If such a principle provided the mechanism by which the first cause existed, it would have "caused" the first cause, which is contradictory, and would only move the problem of existence to the principle. But, if such a principle does not provide a mechanism for the first cause to exist, it does not "explain" it either, because the mechanism by which the first cause exists is one and the same as the "explanation" for how it exists.

Therefore, the mechanism by which the first cause exists is within itself, at least (if the mechanism is not the entirety of the first cause). But, that still leaves unanswered the question of how such a thing can exist. Whatever it is is wholly undesigned, by definition. It never began to exist, by definition. But, without a designer or creator, it is hard to think of what "how it exists" could mean, in this context.

Classical answers to this problem involve asserting that the existence of the first cause was "necessary", i.e., that the alternative was impossible. However, it is hard to see how these arguments could ever demonstrate that the alternative was truly "impossible" (it's certainly possible to imagine nothing existing), rather than just essentially stating that because the first cause happened to exist in this reality, it can be called "necessary". And, something being called "necessary" is not actually a description of how it is attaining existence. It provides a sort of justification, but not a description per se.
